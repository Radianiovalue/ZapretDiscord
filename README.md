> [!WARNING]

> ### Реакция антивирусов
> WinDivert иногда определяется антивирусом.  
> Это инструмент перехвата и фильтрации трафика, необходимый для работы zapret.
> Его могут применять как безопасные, так и вредоносные программы, но сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и попадает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений лучше добавить нужную папку в исключения, но если вы не уверены в своих действиях, рекомендуется отключить детектирование PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", укажите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную вставьте URL. Например: `https://dns.google/dns-query` — провайдер Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах ОС; [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите опцию "Транзит запросов". Если её отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Radianiovalue/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите необходимый файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить автоматический запуск, выберите **`service.bat`** → `Install Service` → подходящую стратегию.

## ℹ️ Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому перебирайте разные варианты — **ALT, FAKE и другие — пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб.
  - **`Check Status`** — показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — включает или отключает обход для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние включения или отключения отображается в скобках.
  - **`IPSet Filter`** — меняет режим обхода сервисов, перечисленных в `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret открывается, а с ним — нет.  
  В скобках отображается один из режимов:
    - `none` — ни один IP не проходит проверку;
    - `loaded` — проверяется принадлежность IP списку;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включает или выключает автоматический поиск обновлений.
  - **`Replace active fakes`** — заменяет используемый фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** — загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновляет hosts <ins>для исправления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** — ищет распространённые причины неисправности zapret.  
  В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало работать.
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — тестирует сайты из `utils/targets.txt`;
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным BAT-файлом, а не через service, должен появиться процесс winws.exe — обход можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/Radianiovalue/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

1. Откройте командную строку с правами администратора.
2. Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

3. Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированное в конец `hosts` или замените ранее добавленный аналогичный фрагмент.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что hosts действительно сохранился.

#### Результат не гарантирован. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Radianiovalue/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> После обнаружения определённая стратегия может прекратить работать, даже если раньше какое-то время давала результат.
> В репозитории собраны разные варианты обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` → `Run Diagnostics` проверьте наличие ошибок.
- Убедитесь, что адрес нужного ресурса присутствует в доменных или IP-списках.
- Попробуйте другие стратегии, например **`ALT`**, **`FAKE`** и прочие.
- Выполните полную переустановку по инструкции ниже.
- Обратитесь к [#765](https://github.com/Radianiovalue/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; если найдены ошибки, исправьте их, затем в конце выберите Y.
- Удалите прежнюю папку zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/Radianiovalue/zapret-discord-youtube/releases), архив вида `zapret-discord-youtube-...`.
- Нажмите правой кнопкой по архиву и откройте свойства. Если в правом нижнем углу есть флажок разблокировки, установите его, нажмите «Применить» и «ОК».
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы.
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если интернет не работает, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы в командной строке Windows, открытой через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если используемый вариант раньше работал.
- Дополнительная информация есть в [#251](https://github.com/Radianiovalue/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно выяснить, какая стратегия открывает YouTube, и запустить её.
- Через `service.bat` → `Run Diagnostics` очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, попробуйте все стратегии ещё раз: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Radianiovalue/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/Radianiovalue/tg-ws-proxy).
- Либо подключитесь к бесплатному MTProto-прокси из интернета.

### Не запускаются игры или не работает сетевое подключение

Игр много, поэтому проверить и исправить каждую невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если результата нет, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно: выясните IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если это тоже не помогло, создайте обсуждение в разделе [Discussions](https://github.com/Radianiovalue/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/Radianiovalue/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть уже указана в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
